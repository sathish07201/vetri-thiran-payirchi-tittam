# System Requirements Specifications

| Component | Minimum Specification | Recommended Specification | Status |
| :--- | :--- | :--- | :--- |
| **Processor** | Intel Core i5 (or AMD equivalent) | Intel Core i7 / Apple Silicon M-series | Verified |
| **RAM** | 4 GB | 8 GB or 16 GB | Verified |
| **Storage** | 128 GB SSD / HDD | 256 GB NVMe SSD | Verified |
| **Network** | Minimum 10 Mbps broadband | 25+ Mbps high-speed internet | Verified |
| **Audio-Visual** | Standard microphone & speakers | Audio-visual headset for sessions | Verified |
| **Browser** | Google Chrome, Firefox, or MS Edge | Latest Google Chrome (v120+) | Verified |
| **IDE** | Visual Studio Code | Visual Studio Code with ESLint & Prettier | Verified |
| **Version Control**| Git (v2.30+) | Git (latest release) with GitHub CLI | Verified |
